## ADDED Requirements

### Requirement: Запоминание размера окна

Приложение MUST открываться с размером 864×576, если сохранённый размер отсутствует. Последний обычный (не развёрнутый) размер окна MUST сохраняться в `.env` рядом с exe при закрытии окна (ключи `WINDOW_WIDTH`, `WINDOW_HEIGHT`) и MUST восстанавливаться при следующем запуске. При закрытии развёрнутого окна MUST сохраняться предыдущий обычный размер, а не размер развёрнутого окна.

#### Scenario: Первый запуск

- **WHEN** приложение запущено впервые, в `.env` нет `WINDOW_WIDTH` и `WINDOW_HEIGHT`
- **THEN** окно открывается с размером 864×576

#### Scenario: Размер запомнился

- **WHEN** пользователь изменил размер окна, закрыл его и запустил приложение снова
- **THEN** окно открывается с сохранённым размером

#### Scenario: Развёрнутое окно не сохраняется

- **WHEN** пользователь развернул окно на весь экран и закрыл его
- **THEN** при следующем запуске окно открывается с предыдущим обычным размером, а не развёрнутым

#### Scenario: Ручная правка размера

- **WHEN** пользователь вручную прописал `WINDOW_WIDTH=1000` и `WINDOW_HEIGHT=700` в `.env`
- **THEN** окно открывается с размером 1000×700
