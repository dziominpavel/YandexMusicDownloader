# Spec Delta

## MODIFIED Requirements

### Requirement: Горячее применение настроек

После успешного сохранения настройки MUST применяться без перезапуска: токен перевалидируется и используется новыми задачами очереди, `OUTPUT_DIR` и `PLAYLIST_WORKERS` действуют для следующих задач (новый лимит воркеров — со следующего освободившегося слота), изменение `LIBRARY_DIR` MUST запускать пересборку индекса или её отключение, `EMBED_COVER`, `EMBED_LYRICS`, `CONVERT_M4A` и подпапки действуют для следующих файлов. Сохранение MUST NOT прерывать активные загрузки.

#### Scenario: Сменил токен без перезапуска

- **WHEN** пользователь сохранил новый валидный токен при активной очереди и сразу вставил новую ссылку
- **THEN** новая задача качается с новым токеном, активные загрузки не прерываются, перезапуск приложения не требуется

#### Scenario: Выключил проверку дублей

- **WHEN** пользователь сохранил настройки с пустым `LIBRARY_DIR`
- **THEN** индексация и вопросы о дублях выключаются, скачивание продолжает работать

#### Scenario: Сменил число воркеров

- **WHEN** пользователь изменил `PLAYLIST_WORKERS` при активной очереди
- **THEN** следующая освободившаяся задача запускается по новому лимиту, а уже качающиеся задачи не прерываются

## ADDED Requirements

### Requirement: Настройки во время активной очереди

Окно настроек MUST открываться независимо от того, идут ли загрузки. Сохранение MUST применяться к новым задачам и MUST NOT прерывать активные. Если изменение влияет на выполняющиеся задачи (токен, `OUTPUT_DIR`, `PLAYLIST_WORKERS`), окно MUST явно сообщать, что текущие загрузки завершатся со старыми параметрами, а новые задачи возьмут новые.

#### Scenario: Открыть настройки во время загрузки

- **WHEN** в очереди есть активные задачи и пользователь нажимает «Настройки»
- **THEN** форма открывается, а загрузки продолжаются в фоне

#### Scenario: Сохранить папку во время загрузки

- **WHEN** пользователь сменил `OUTPUT_DIR` при активной загрузке и сохранил
- **THEN** активные задачи дописываются в прежнюю папку, а новые задачи используют новую

#### Scenario: Сохранить токен во время загрузки

- **WHEN** пользователь сохранил новый токен при активной загрузке
- **THEN** активные задачи не прерываются, а новые запускаются с новым токеном

## REMOVED Requirements

### Requirement: Настройки закрыты на время скачивания

**Reason**: Очередь может работать часами, поэтому блокировка настроек на всё время загрузки делает их недоступными; изменения теперь применяются к новым задачам и не прерывают текущие.

**Migration**: Настройки открываются в любой момент; предупреждение в форме объясняет, какие изменения вступят в силу со следующих задач.
