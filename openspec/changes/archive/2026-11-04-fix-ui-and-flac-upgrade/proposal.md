# Proposal

## Why

В окне «Найдены треки в лучшем качестве» кнопка «Скачать все» скачала новые FLAC в папку коллекции (`LIBRARY_DIR`), а не в папку загрузок (`OUTPUT_DIR`). Причина — расхождение спек: `track-download` требует качать в `OUTPUT_DIR`, а `quality-upgrade` предписывает публиковать файл рядом со старым. Пользователь ожидает, что любая загрузка идёт в папку из настроек, а коллекция остаётся только для чтения.

Одновременно в главном окне есть несколько дефектов: пустая иконка в панели задач, иконка настроек выглядит как солнце, строка «FLAC: проверка идёт…» остаётся после завершения проверки, а кнопка FLAC в шапке дублирует действие, которое уже есть в настройках.

## What Changes

- **BREAKING (поведение)**: новый lossless при FLAC-обновлении всегда публикуется в `OUTPUT_DIR` (с учётом `SUBDIRS` и обычного имени `Исполнитель - Название.ext`), а не рядом со старым MP3. В `LIBRARY_DIR` новый аудиофайл не пишется.
- Старый MP3 после успешной публикации перемещается в `<корень старого файла>\_old\<относительный путь>`; при занятом имени добавляется метка времени. Сайдкар `.lrc` старого файла перемещается в `_old` вместе с ним.
- Если FLAC с тем же треком уже есть в `OUTPUT_DIR` или рядом со старым MP3, повторно не скачиваем: только архивируем старый MP3 в `_old`.
- Окно найденного показывает папку назначения нового FLAC и правило архивирования старого файла.
- Кнопка FLAC, её бейдж и строка статуса убираются из шапки главного окна. Ручная проверка запускается из раздела «Мониторинг FLAC» в настройках.
- Количество найденных обновлений показывается бейджем на кнопке «Настройки»; бейдж обновляется после проверки и после обновления.
- Автопроверка больше не открывает окно найденного сама: она обновляет бейдж и статус, окно открывается действием пользователя.
- «Проверить сейчас» в настройках выполняет проверку, не закрывая форму и не теряя несохранённые правки; по завершении показывает фактический результат, а не «проверка идёт…».
- Исправлен порядок формирования текста завершения проверки: событие `quality-check-finished` несёт результат проверки, а не состояние выполнения.
- Группа иконок в Windows-ресурсах получает числовой ID 3, который ищет Wails, — панель задач показывает иконку приложения вместо стандартной.
- Иконка настроек заменяется на нормальную шестерёнку в том же векторном стиле.
- Настройки папок и чекбокс «Папка загрузок отличается от папки коллекции» **не меняются**.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `quality-upgrade`: назначение нового FLAC, обработка уже существующего FLAC, содержимое и точка входа окна найденного, индикация результата проверки.
- `desktop-app`: удаление кнопки и статуса FLAC из шапки, бейдж найденного на кнопке «Настройки», корректировка сценариев визуальной иерархии.
- `app-settings`: раздел мониторинга FLAC как единственная точка ручного запуска, проверка без закрытия формы, корректный результат после завершения.

## Impact

- `src/internal/downloader/lossless.go` — `Upgrade` принимает папку назначения и использует обычное имя/`SUBDIRS` вместо имени старого файла.
- `src/internal/quality/upgrader.go` — передача `OUTPUT_DIR`, перемещение старого MP3 и `.lrc` в `_old`, логи с путями.
- `src/internal/ui/quality.go` — порядок сброса `checking`, текст события завершения, путь назначения в статусе.
- `src/internal/ui/app.go` — состояние бейджа и настроек.
- `src/frontend/dist/index.html`, `src/frontend/dist/app.js`, `src/frontend/dist/app.css` — шапка, шестерёнка, раздел настроек, модалка найденного.
- `assets/winres/winres.json` — числовой ID группы иконок.
- Тесты: `src/internal/quality/upgrader_test.go`, `src/internal/ui/quality_test.go`, `tests/settings_check.js`, при необходимости новый JS-стенд для бейджа и проверки из настроек.
- Документация: `docs/15-flac-monitor.md`, `docs/16-ui-design.md`, `CHANGELOG.md`.
- Учесть незавершённый change `add-startup-animation`, который уже правит `src/frontend/dist/index.html` и `app.css`.
