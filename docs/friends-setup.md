# Инструкция для друзей: как качать музыку

Нужно: Windows 10/11 и два файла в одной папке — `app.exe` и `.env`.

## 1. Получить токен (один раз)

Вариант А — через браузер:

1. Открой ссылку (вошёл в свой Яндекс-аккаунт):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
2. Нажми «Войти» / разреши доступ.
3. Браузер перекинет на `music.yandex.ru/#access_token=...` — скопируй значение `access_token`
   (длинная строка между `access_token=` и `&token_type=`).

Вариант Б — утилитой `yandex-oauth-token` (покажет QR, токен выдаст сама):
`https://github.com/Stmol/yandex-oauth-token`

## 2. Положить `.env` рядом с exe

В папке с `app.exe` создай файл `.env` (без расширения!) с текстом:

```
YANDEX_TOKEN=вставь_свой_токен_сюда
```

Папка `downloads/` создастся сама при первом скачивании.

## 3. Качать

1. Запусти `app.exe` двойным кликом (чёрного окна не будет — так задумано).
2. На Яндекс Музыке: Поделиться → Скопировать ссылку на трек.
3. Вставь ссылку в поле, нажми «Скачать».

Строки в логе:

| Строка | Что значит |
|--------|-----------|
| `[downloading] Артист — Трек` | качается |
| `[done] Артист — Трек (FLAC)` / `(M4A)` | готово, лучшее качество |
| `[done] ... (MP3) [fallback MP3]` | lossless нет — скачан лучший MP3, это нормально |
| `[skip] ... (already exists)` | уже скачан раньше |
| `[error] ...` | ошибка, текст причины — рядом |

Без токена качаются только 30-секундные превью.

## 4. Автоконвертация ALAC → FLAC (по желанию)

Некоторые треки Яндекс хранит в lossless как ALAC (файл `.m4a`), а не FLAC —
такие файлы часть плееров и магнитол не читает. Если рядом с `app.exe`
положить `ffmpeg.exe`, программа сама перегонит такие треки во FLAC
на лету (звук тот же бит-в-бит, теги пишутся как обычно), в логе будет
`[done] ... (FLAC) [ALAC→FLAC]`. Без `ffmpeg.exe` всё работает как раньше,
просто останутся `.m4a`. Отключить конвертацию: добавить в `.env`
`CONVERT_M4A=false`.

## Если что-то не так

- «токен НЕ принят» при запуске — токен скопирован с ошибкой или протух, получи заново (шаг 1).
- Окно не открывается на старой Windows — нужен WebView2 (в Win10/11 уже встроен).
- Токен — как пароль: никому не пересылай, в чаты не выкладывай.

## Для сборщика (не друзьям)

Один exe собирается только так (Wails требует теги, иначе exe покажет диалог об ошибке):

```powershell
.\scripts\build-windows.ps1
```

Вручную: `go build -tags 'desktop,production' -ldflags '-H=windowsgui' -o app.exe ./cmd/app` из папки `src/`.
