# 16. UI-дизайн: Warm Vinyl

*Основано на change `openspec/changes/redesign-ui`.*

## Назначение

Единая визуальная система десктопного окна: тёплый тёмный интерфейс, один акцент для главного действия, спокойная типографика и явные состояния экрана. Дизайн не меняет логику скачивания и не превращает приложение в музыкальный менеджер.

## Палитра

```css
:root {
  --bg:           #12100F;
  --surface:      #1C1817;
  --surface-2:    #26201E;
  --surface-3:    #312925;
  --border:       #3A302D;
  --border-strong:#4A3C36;
  --text:         #F5EEE8;
  --text-muted:   #B7A8A0;
  --text-faint:   #8A7B73;
  --accent:       #F0A35E;
  --accent-hover: #FFB877;
  --accent-press: #D98A45;
  --accent-ink:   #1A120D;
  --success:      #8FD3A0;
  --warning:      #E8C468;
  --danger:       #E06C5F;
  --danger-hover: #F07F72;
  --focus:        #FFC98A;
  --shadow:       0 12px 32px rgba(0, 0, 0, .35);
}
```

Правила:

- акцентная заливка — только у главного действия;
- текст на акцентной заливке — `--accent-ink`, не белый;
- красный — только остановка и ошибки, не «найдено лучшее качество»;
- янтарный — предупреждения и найденный FLAC;
- зелёный — успешное завершение.

## Типографика

- Интерфейс: `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif`.
- Заголовки: `"Segoe UI Variable Display", "Segoe UI", system-ui, sans-serif`.
- Лог и технические значения: `"Cascadia Mono", Consolas, monospace`.
- База 14 px, вторичный текст 13 px, подписи 12 px, заголовки 20–24 px.
- Высота строки 1.35–1.5; вес 400/500/600.
- Проценты, байты и счётчики — `font-variant-numeric: tabular-nums`.
- Моноширинный шрифт не используется в названиях треков и статусах.

## Сетка и форма

- Отступы: 4, 8, 12, 16, 24, 32 px.
- Радиусы: 8 px — контролы, 10–14 px — карточки и модалки.
- Границы: 1 px `--border`; у активных поверхностей — `--border-strong`.
- Тени: только у модалок и всплывающих карточек.
- Focus-ring: 2 px `--focus` с offset 2 px, не убирать `outline` без замены.
- Анимации: 140–180 мс; при `prefers-reduced-motion: reduce` отключить переходы.

## Состояния главного экрана

```text
idle -> preview -> active -> done
                       \--> error
                       \--> done (stopped)
```

- **idle** — поле, главная кнопка, подсказка, drag & drop; статусбара нет.
- **preview** — карточка обложки, названия, артистов, типа и количества треков; «Скачать» не блокируется.
- **active** — один агрегированный прогресс и один список треков; главная кнопка — «Остановить».
- **done** — итоговая сводка, «Открыть папку», «Скачать ещё»; лог свёрнут.
- **error** — inline-ошибка, «Повторить», технические детали в «Подробностях».

## Компоненты

### Кнопки

- **Primary**: accent-заливка, тёмный текст, высота 40–44 px.
- **Secondary**: прозрачный фон, 1 px border, hover — `--surface-2`.
- **Ghost**: только текст/иконка, hover — `--surface-2`.
- **Danger**: `--danger` для остановки; hover — `--danger-hover`.
- **Disabled**: приглушённая заливка и текст, `cursor: not-allowed`; не `wait`, если действие не выполняется.
- **Icon-only**: 36×36, SVG 20×20, `aria-label`, tooltip.

### Поля и чекбоксы

- Тёмный фон `--surface`, border `--border`, текст `--text`.
- Placeholder — `--text-faint`.
- Focus — border `--focus` + ring.
- Чекбокс — квадрат 16×16, accent-заливка при выборе, доступный label.
- Ошибка поля — `--danger` и текст рядом.

### Прогресс

- Общая полоса: 8–10 px, `role="progressbar"`, `aria-valuenow`, `aria-label`.
- Строка трека: индекс, название, формат-пилюля, тонкая полоса, размер, статус.
- Проценты и байты — tabular nums; обновления не чаще 200 мс.
- Статусы: «Ожидание», «Скачивается», «Готово - FLAC/MP3», «Пропущено - ...», «Ошибка - ...».

### Модалки

- `role="dialog"`, `aria-modal="true"`, `aria-labelledby`.
- Шапка и footer фиксированы, тело прокручивается.
- Focus trap; Escape закрывает; при несохранённых изменениях — confirm.
- Primary-действие одно; destructive — красное.

## Настройки

- Две колонки, секции: Аккаунт, Папки, Качество, Теги, Производительность, Мониторинг.
- Sticky footer: «Отмена» (ghost) и «Сохранить» (primary); шапка и footer не прокручиваются, тело формы — прокручивается.
- Снимок формы при открытии, `isDirty()`, защита от потери изменений: Escape, клик по фону и крестик при изменениях открывают confirm; «Отмена» закрывает без вопроса.
- Focus trap: Tab циклически остаётся внутри модалки, начальный фокус — в первом поле, после закрытия — в поле ссылки.
- Подписи объясняют назначение; технический ключ `.env` — не единственная подпись.
- Пример шаблона подпапок: `Music/Muse/Absolution/01 - Hysteria.flac`.

## Доступность

- Все интерактивные элементы имеют доступное имя.
- Прогресс и терминальные статусы объявляются через `aria-live`; ошибки — `role="alert"`.
- Модалки удерживают фокус; после закрытия фокус возвращается в поле ссылки.
- Контраст текста — не ниже WCAG AA; проверить accent-пары вручную.
- Поддержать `prefers-reduced-motion`.

## Окно и брендинг

- Минимум 860×600 DIP; без горизонтальной прокрутки.
- Фон Wails — `#12100F`, системный заголовок — тёмный.
- Иконка `assets/icon.png`/`icon.ico`, `ProductName`, `FileDescription`, `FileVersion` из `version`.
- Манифест: DPI awareness PerMonitorV2.
