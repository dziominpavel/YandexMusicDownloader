## Purpose

Каждый скачанный файл MUST содержать корректные теги и обложку: коллекция должна быть пригодна для плеера без ручной правки. Это закрывает главную боль референса Stmol.

## Requirements

### Requirement: Обязательные теги

Приложение MUST записывать в каждый файл: название, исполнителя(ей), альбом, год, номер трека и всего треков, жанр, идентификатор трека (`YM_ID`), обложку. Теги пишутся до публикации файла.

#### Scenario: Проверка тегов FLAC

- **WHEN** скачивание FLAC завершено
- **THEN** в файле есть `TITLE`, `ARTIST`, `ALBUM`, `DATE`, `TRACKNUMBER`, `TRACKTOTAL`, `GENRE`, обложка

### Requirement: Мультиартист

При нескольких исполнителях приложение MUST записывать каждого отдельным полем, а не одной строкой через запятую.

#### Scenario: Фит двух артистов

- **WHEN** у трека два исполнителя
- **THEN** плеер показывает обоих как отдельных артистов (навигация по каждому работает)

### Requirement: Обложка

Приложение MUST встраивать обложку в тег файла. Отдельное сохранение `cover.jpg` рядом — опционально. Флаг `SKIP_COVER=true` MUST отключать только обложку, текстовые теги при этом пишутся как обычно.

#### Scenario: Пропуск обложки

- **WHEN** задан `SKIP_COVER=true`
- **THEN** файл содержит все текстовые теги, но без встроенной картинки

### Requirement: Имена файлов

Имя файла MUST собираться по шаблону `%author%/%year% - %album%/%num% - %title%.flac` (шаблон настраивается), запрещённые для файловой системы символы MUST заменяться на `_`.

#### Scenario: Альбом из 10 треков

- **WHEN** скачивается альбом из 10 треков
- **THEN** файлы лежат в одной папке альбома с нумерацией `01`, `02`, …, `10`
