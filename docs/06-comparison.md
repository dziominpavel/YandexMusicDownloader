## Выводы

1. Рабочая база — Stmol. Остальное — доноры.
2. Теги — брать у nnikitochka, там закрыта боль Stmol.
3. Крипту сверить по Kud1nov (тесты подписи) + MarshalX (SALT).
4. MarshalX — лучший источник истины по API, но не качалка.
5. Ни у кого нет идеального UX «вставил-скачал» + иерархии альбомов — делаем сами.

## Риски API (общие)

- Смена `SIGN_SALT / SignKey / client_id / User-Agent` ломает все.
- `direct_link` живет ~60 сек — рефрешить перед каждым файлом.
- Без Plus часть треков `available=false`.
- Капча/2FA кроме push ломают авто-авторизацию — поэтому токен храним в `.env`, получаем вручную один раз.
