# 09. Стек (решение зафиксировано)

## Решение (08.09.2026)

- **Язык: Go.** Причины: собирается в один `app.exe` без рантайма (требование — раздавать друзьям exe + инструкция, без кода); протокол скачивания уже есть на Go у Stmol — портируем, а не пишем с нуля; конкурентность из коробки.
- **UI: полноценное Windows-окно** (не консоль, не веб). Кандидаты:
  - **Wails v2** (дефолт): Go-бэкенд + WebView2-фронт, exe ~10 МБ, современный UI; WebView2 встроен в Win10/11.
  - **Fyne**: чистый Go без WebView2, бинарник больше, UI проще.
  - Окончательный выбор Wails vs Fyne — на этапе дизайна первого change'а.
- **Дистрибуция:** один `.exe` + `инструкция` (как получить токен, куда положить `.env`/токен, нажал — скачалось).
- **Токен v0.1:** ручной (как сейчас) + понятная инструкция; встроенный `device_auth` — позже, если понадобится.
- **Контент v0.1:** только треки; альбомы/плейлисты — v0.2.
- **Шаблон папок (дефолт):** иерархия `Author/Album/NN - Title.flac`.
  > Отменено 09.09.2026: выбрана плоская раскладка `Группа - Трек` с сортировкой кириллицы — см. `docs/12-file-naming.md`.

## Рассмотренные варианты (история)

## Вариант A — Python (рекомендую для скорости)

- `yandex-music-api (MarshalX)` + `mutagen` (теги) + `requests/httpx` + `python-dotenv`.
- UI v0.1: CLI (`вставил → скачал`) или tiny-web (`Flask/FastAPI + 1 страница`).
- Плюсы: готовый транспорт+auth+device_auth, куча примеров, теги через `mutagen` проще всего, быстрее прототип.
- Минусы: нужен Python + `pip install`, exe делать через PyInstaller (тяжелее чем Go).
- Подходит если главное — FLAC + теги уже завтра.

## Вариант B — Go single-binary (как Stmol)

- Форк логики Stmol + Tag-схема от nnikitochka (портировать `jaudiotagger` карту на `go-flac/id3v2/mtag`).
- UI: CLI (`download --link`) + позже минимальный TUI/web.
- Плюсы: один `app.exe` без зависимостей (тебе такой формат нравился), быстро, конкурентность из коробки.
- Минусы: дольше писать теги/жанры/шаблоны с нуля, меньше примеров чем в Python-мире.

## Что не советую

- Kotlin/JVM (nnikitochka): тяжелые рантаймы, мало смысла для личной качалки на Windows.
- Писать транспорт с нуля: берем готовые формулы подписи/шифра, не реверсим заново.
