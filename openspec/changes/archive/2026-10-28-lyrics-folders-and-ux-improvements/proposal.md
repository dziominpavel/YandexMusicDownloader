# Proposal

## Why

Пользователи хотят видеть текст песни прямо в плеере без постобработки, лучше организовывать скачанную коллекцию по альбомам при необходимости и получать больше удобства в повседневной работе (drag&drop, предпросмотр, история, быстрая навигация к папке загрузок).

## What Changes

- **Лирика**: встраивать текст песни в тег файла по умолчанию (`LYRICS`/`USLT`/`©lyr`) для FLAC/MP3/M4A. Опционально сохранять синхронизированную лирику `.lrc` рядом с файлом. Настройки поведения — в окне настроек.
- **Организация файлов**: опциональное создание подпапок по шаблону (по умолчанию выкл, шаблон `Исполнитель/Альбом/` с учётом правила сортировки кириллицы из `docs/12-file-naming.md`). Опциональный экспорт плейлиста/альбома в `.m3u` (по умолчанию выкл).
- **UX (без настроек)**: Drag & Drop ссылок, кнопка «Открыть папку загрузок», история последних ссылок (localStorage), предпросмотр ссылки (обложка/название/артист/кол-во треков) без блокировки скачивания.

## Capabilities

### New Capabilities
- Нет новых capability-путей.

### Modified Capabilities
- `audio-tagging`: добавить поддержку встраивания текста песни в теги (FLAC/MP3/M4A).
- `track-download`: добавить опциональное создание подпапок, экспорт `.m3u`, получение лирики и UX-улучшения (drag&drop, история, предпросмотр, открытие папки).

## Impact

- **Tagger**: встраивание лирики в теги для всех форматов, получение лирики из API.
- **Config/UI (Go)**: новые настройки в `.env`/настройках (embed_lyrics, save_lrc, subdirs, subdir_template, export_m3u), формирование пути скачивания, экспорт m3u, открытие папки.
- **Frontend**: drag&drop, история ссылок, предпросмотр, кнопка открытия папки.
- **Спеки**: обновить `audio-tagging` и `track-download` дельтами.
