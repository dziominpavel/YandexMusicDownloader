# 08. Требования (v0.1)

## Функциональные

- [ ] F1. Чтение токена из `.env` (`YANDEX_TOKEN`). Без токена — только 30 сек превью + предупреждение.
- [ ] F2. Вставка ссылки на трек → кнопка «Скачать». (Альбом/плейлист/чарт — v0.2.)
- [ ] F3. Скачивание FLAC если доступен, иначе лучший MP3 + пометка fallback.
- [ ] F4. Теги обязательны: название, артисты (мульти), альбом, год, номер/всего, жанр, обложка, `YM_ID`.
- [ ] F5. Пропуск если файл уже есть (`AlreadyExists`).
- [ ] F6. Строковый лог: `[downloading]/[done]/[fallback]/[skip]/[error]`.
- [ ] F7. Папка `downloads/` создается сама, имена санитизированы.
- [ ] F8. `--skip-cover` / `SKIP_COVER` оставляет текстовые теги.

## Нефункциональные

- N1. Один запуск без `pip/brew/apt` в идеале (плюс Go) или одна команда `pip install` (плюс Python).
- N2. Не держать весь FLAC в RAM — стриминг.
- N3. Атомарная запись (`temp→rename`).
- N4. Токен никогда в git (`.env` в `.gitignore`).
- N5. Только личное использование.

## UX v0.1

```
[_________________ вставь ссылку _________________] [Скачать ▼ FLAC]
[downloading] Artist — Title
[done] Artist — Title (FLAC)
```

Никаких табов, хоткеев, `TERM=xterm` приколов.

## Вне скоупа v0.1

Поиск, лайки, очередь с паузой, многодисковые тонкости, тексты песен в тег (только `.lrc` рядом — можно), выбор битрейта вручную.
