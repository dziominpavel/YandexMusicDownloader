# Spec Delta

## ADDED Requirements

### Requirement: Справка у поля токена

Окно настроек MUST показывать рядом с полем «Токен Яндекс» действие «Как получить токен?», открывающее встроенную справку. Пока токен пуст, окно MUST дополнительно предупреждать, что без токена доступно только 30-секундное превью.

#### Scenario: Токен не задан — видна подсказка

- **WHEN** пользователь открыл настройки, а токен пуст
- **THEN** под полем токена видно предупреждение про 30-секундное превью и действие «Как получить токен?»

#### Scenario: Токен уже задан

- **WHEN** пользователь открыл настройки, а токен уже сохранён
- **THEN** действие «Как получить токен?» остаётся доступным, предупреждение про превью не показывается

#### Scenario: Открыл и закрыл справку

- **WHEN** пользователь нажал «Как получить токен?», затем закрыл справку
- **THEN** окно настроек остаётся открытым, введённые значения (включая набранный токен) не теряются

### Requirement: Содержание справки «Как получить токен»

Справка MUST объяснять, зачем нужен токен, и содержать пошаговую инструкцию: открыть официальную OAuth-страницу Яндекса, разрешить доступ, скопировать `access_token` из адресной строки, вставить токен в поле и проверить. Справка MUST открывать OAuth-страницу в системном браузере и MUST NOT навигировать окно приложения. Справка MUST работать без сети (кроме открытия OAuth-страницы) и MUST предупреждать, что токен нельзя никому передавать.

#### Scenario: Открыл страницу OAuth

- **WHEN** пользователь нажал в справке «Открыть страницу OAuth»
- **THEN** официальная страница `oauth.yandex.ru` открывается в системном браузере, а окно приложения остаётся на справке

#### Scenario: Не успел скопировать токен

- **WHEN** пользователь прочитал шаг про копирование `access_token`
- **THEN** в справке есть подсказка, что делать при быстром редиректе: открыть ссылку в инкогнито или нажать `Ctrl+L`, затем `Ctrl+C` сразу после возврата на сайт

#### Scenario: Предупреждение о безопасности

- **WHEN** пользователь открыл справку
- **THEN** видно предупреждение, что токен действует как пароль и его нельзя пересылать или публиковать
