# 11. Как получить токен Яндекс Музыки

Пошаговая инструкция для обычных пользователей (без программирования).
Время: 2–5 минут. Делается **один раз**.

## Зачем нужен токен

`YANDEX_TOKEN` — это ключ, по которому приложение обращается к Яндекс Музыке
от вашего имени:

- без токена — качаются только 30-секундные превью;
- с токеном — полные треки;
- с токеном от аккаунта **с подпиской Плюс** — lossless (FLAC), иначе только MP3.

Токен вводится один раз в окне приложения («⚙ Настройки») или вручную в `.env`, больше ничего делать не нужно.

> Связанные доки: `docs/01-overview.md` (сценарий), `docs/08-requirements.md`
> (требование F1), `docs/05-repo-marshal.md` (технические детали auth).

## Важно про безопасность

1. **Токен = пароль.** Кто владеет токеном — слушает музыку и управляет
   вашим аккаунтом Музыки от вашего имени.
2. **Никому не показывайте и не пересылайте** токен, скриншоты адресной
   строки с токеном, файл `.env`.
3. **Не коммитьте `.env` в git.** В репозиторий уходит только
   `.env.example` без значений. `.env` уже добавлен в `.gitignore`.
4. Если токен случайно засветился — отзовите его (раздел в конце) и выпустите новый.

Как выглядит токен: длинная строка из букв, цифр, `_` и `-`,
обычно начинается на `y0_` или `AQAAAA...`. Пример (выдуманный, не рабочий):

```text
y0_AgAAAAAxxxxxxxxxxxAAA... (очень длинный, ~200+ символов)
```

## Что понадобится

- Аккаунт Яндекса, которым вы пользуетесь в Яндекс Музыке.
- Для FLAC — **активная подписка Яндекс Плюс** на этом же аккаунте.
  Без Плюса приложение всё равно будет работать, но качать MP3 320
  с пометкой `[fallback]` в логе. Это нормально.
- Браузер Chrome / Edge / Firefox.

## Способ 1 (рекомендуемый): через браузер, за 2 минуты

Ничего устанавливать не нужно.

### Шаг 1. Откройте страницу выдачи токена

Перейдите по этой ссылке (это официальный OAuth Яндекса,
`client_id` — от Android-приложения Яндекс Музыки, так делают все
сторонние качалки):

```text
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

### Шаг 2. Войдите и разрешите доступ

1. Если попросит — войдите в нужный аккаунт Яндекса.
2. Появится экран «Приложение запрашивает доступ» — нажмите
   **«Войти как ...»** / **«Разрешить»**.

### Шаг 3. Поймайте токен в адресной строке

Браузер перекинет вас на `music.yandex.ru` с адресом вида:

```text
https://music.yandex.ru/#access_token=y0_AgAAAAA...&token_type=bearer&expires_in=31535645
```

Нужное — это значение между `access_token=` и следующим `&`.

Проблема: страница `music.yandex.ru` редиректит очень быстро и затирает
адресную строку. Если не успели скопировать:

1. Откройте эту же OAuth-ссылку **в окне инкогнито** или
2. заранее откройте DevTools (`F12` → вкладка **Network**), включите
   троттлинг сети (в Chrome: выпадающий список `No throttling` →
   `Slow 3G`), и только потом открывайте ссылку. Редирект замедлится,
   и вы успеете скопировать URL.
3. Альтернатива: после редиректа нажмите `Ctrl+L` (фокус в адресную
   строку), `Ctrl+C` — иногда полный URL с `#access_token=...`
   сохраняется в буфере, даже если визуально его уже нет.

Скопируйте **только токен** (без `access_token=`, без пробелов и переносов).

### Шаг 4. Вставьте токен в приложение

Самый простой путь — через окно настроек:

1. Запустите `app.exe`.
2. Нажмите «⚙ Настройки».
3. Вставьте токен в поле «Токен Яндекс» и нажмите «Проверить» — должно появиться `ок: ...`.
4. Нажмите «Сохранить». Приложение само запишет токен в `.env` рядом с exe и применит его без перезапуска.

Если не знаете, где взять токен, в настройках есть ссылка «Как получить токен?» с короткой инструкцией и кнопкой открытия страницы OAuth.

**Запасной вариант — вручную в `.env`.** Если приложение не запускается или нужно подготовить файл заранее:

1. Создайте рядом с `app.exe` файл `.env` (без расширения). Если он уже есть — откройте его.
2. Впишите строку:

   ```ini
   YANDEX_TOKEN=y0_ваш_длинный_токен_сюда_без_пробелов
   ```

   Без кавычек, без пробелов вокруг `=`. Сохраните.
3. Перезапустите приложение, чтобы оно прочитало `.env`.

Готово. Дальше — вставьте ссылку на трек в приложение и нажмите «Скачать».

## Способ 2: через готовые инструменты (если способ 1 не сработал)

Для некоторых аккаунтов implicit-flow в браузере не выдаёт токен
(Яндекс периодически закручивает гайки). Тогда:

| Вариант | Где взять | Как пользоваться |
|---|---|---|
| Сайт-получалка | <https://music-yandex-bot.ru/> | Войти через Яндекс, нажать «Получить токен», скопировать. Работает не для всех аккаунтов. |
| Расширение Chrome | [yandex-music-token в Chrome Web Store](https://chrome.google.com/webstore/detail/yandex-music-token/lcbjeookjibfhjjopieifgjnhlegmkib) | Установить, открыть Яндекс Музыку залогиненным, нажать на иконку расширения → `Copy token`. |
| Расширение Firefox | [yandex-music-token для Firefox](https://addons.mozilla.org/en-US/firefox/addon/yandex-music-token/) | То же самое для Firefox. |
| Android-приложение | [APK в релизах yandex-music-token](https://github.com/MarshalX/yandex-music-token/releases) | Установить APK, войти, скопировать токен. Код всех инструментов открыт: <https://github.com/MarshalX/yandex-music-token>. |

Дальше — тот же шаг 4: вставьте токен в настройках приложения (или в `.env` вручную).

## Способ 3: через Python (для продвинутых)

Тот же Device Flow, что описан в `docs/05-repo-marshal.md`. Нужен Python 3.8+.

```powershell
pip install yandex-music
```

Создайте файл `get_token.py`:

```python
from yandex_music import Client

def on_code(code):
    print(f'Откройте {code.verification_url} и введите код: {code.user_code}')

client = Client()
token = client.device_auth(on_code=on_code)

print(f'access_token:  {token.access_token}')
print(f'refresh_token: {token.refresh_token}')
print(f'expires_in:    {token.expires_in}')
```

Запустите:

```powershell
python get_token.py
```

1. Скрипт выведет ссылку и код вида `123 456`.
2. Откройте ссылку, введите код, подтвердите вход.
3. Скрипт напечатает `access_token` — вставьте его в настройках приложения или в `.env`.

Плюс способа: получаете заодно `refresh_token` и видите логин
(`client.init(); print(client.me.account.login)`) — удобно проверить,
что токен от правильного аккаунта.

## Как проверить, что токен рабочий

1. Откройте «⚙ Настройки», вставьте токен и нажмите «Проверить» — должно появиться `ок: ...`.
   Если правили `.env` вручную, убедитесь, что строка `YANDEX_TOKEN=...` заполнена и файл сохранён.
2. Нажмите «Сохранить». При ручной правке `.env` перезапустите приложение.
3. Вставьте ссылку на известный трек и скачайте:
   - `[done] Artist — Title (FLAC)` — всё отлично, есть Плюс и lossless;
   - `[fallback] Artist — Title (MP3)` — токен рабочий, но lossless
     недоступен (нет Плюса или прав на трек). Тоже норма.
   - `[error] 401 / Unauthorized` — токен битый, обрезан или отозван.
     Получите заново и проверьте, что скопировали целиком.

## Частые проблемы

**Скопировал, а пишет 401 Unauthorized.**
Токен обрезан (не влез в Блокнот/мессенджер), есть лишний пробел или
перенос строки, кавычки вокруг значения. В `.env` должно быть ровно
`YANDEX_TOKEN=<токен>` в одну строку. Скопируйте заново целиком.

**Не успел скопировать токен — страница мигнула и пропала.**
См. шаг 3: инкогнито + троттлинг сети в DevTools + `Ctrl+L, Ctrl+C`
сразу после редиректа.

**Токен есть, но качает только MP3, а не FLAC.**
Проверьте: 1) Плюс активен именно на этом аккаунте,
2) трек вообще существует в lossless (у части каталога его нет),
3) вы вошли тем же аккаунтом в браузере, с которого брали токен.
Без Плюса fallback на MP3 — ожидаемое поведение, не ошибка.

**«Своё OAuth-приложение создать нельзя».**
Да, Яндекс не даёт регистрировать свои приложения для Музыки,
поэтому все пользуются `client_id=23cabbb...` от официального
Android-клиента. Это штатная практика (см. `docs/05-repo-marshal.md`).

**Токен перестал работать через месяцы/годы.**
Мог истечь `expires_in` или вы сменили пароль / отозвали доступы.
Получите новый тем же способом и замените в `.env`.

**Боюсь вводить пароль на стороннем сайте (способ 2).**
Правильно. Предпочитайте способ 1 (только официальный `oauth.yandex.ru`)
или способ 3. Сторонние сайты и APK — только если способ 1 не сработал,
и после этого смените пароль при малейших сомнениях.

## Как отозвать токен

- Смените пароль Яндекс ID — все выданные токены сгорят; **или**
- откройте `https://id.yandex.ru/` → «Безопасность» / «Приложения и устройства» →
  отзовите доступ у лишних приложений.

После отзыва замените токен в `.env` на новый.

```powershell
# 1. Открыть в браузере:
# https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
# 2. Скопировать access_token из адресной строки
# 3. app.exe → ⚙ Настройки → вставить токен → Проверить → Сохранить
# Ручной вариант — создать .env рядом с app.exe:
# YANDEX_TOKEN=вставить_токен_сюда
```
