# Proposal

## Why

Между кликом по `app.exe` и первым кадром сейчас два разрыва: проверка токена (`config.Validate`, HTTP с таймаутом 15 с) выполняется в `NewApp` до `wails.Run`, а после создания окна WebView2 ещё некоторое время показывает пустой тёмный прямоугольник. На медленной сети окна нет вообще, на быстрой старт выглядит как пауза без обратной связи. Короткая заставка на ~1 секунду делает запуск осознанным, а перенос проверки токена в фон гарантирует, что окно появляется сразу.

## What Changes

- Добавить в `src/frontend/dist/index.html` слой заставки Warm Vinyl: векторная анимация ~1 с на CSS/SVG (винил и wordmark), без видео, GIF, Lottie и новых зависимостей.
- Заставка живёт в первом кадре страницы, не блокирует ввод и снимается по таймеру; `prefers-reduced-motion` показывает статичный вариант.
- Добавить fail-open: если JavaScript заставки не выполнился, слой исчезает по CSS-таймауту, а главный экран остаётся доступным; в тестовой среде без таймеров заставка снимается сразу.
- Перенести проверку токена из `NewApp`/`apply` в фоновую задачу после открытия окна: клиент создаётся сразу, результат проверки приходит в лог, а `Download` и `PreviewLink` получают понятную русскую ошибку при невалидном токене. Сохранение настроек продолжает проверять токен синхронно.
- Обновить `docs/16-ui-design.md` и `CHANGELOG.md`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `desktop-app`: запуск окна, заставка ~1 с и отсутствие блокирующей проверки токена до первого кадра.

## Impact

- `src/frontend/dist/index.html`, `app.css`, `app.js` — разметка, стили и снятие заставки.
- `src/internal/ui/app.go` — `NewApp`/`apply`/`Startup`/`Download`/`PreviewLink`, инъекция проверки токена для тестов.
- `src/internal/ui/*_test.go` — тесты фоновой проверки и ошибок токена.
- `tests/statusbar_check.js` — проверка, что заставка не ломает существующие сценарии; при необходимости новый `tests/splash_check.js`.
- `docs/16-ui-design.md`, `CHANGELOG.md`.
- Без изменений API, ключей `.env`, зависимостей и форматов файлов.
