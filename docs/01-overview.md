# 01. Цель и сценарий

## Что строим

Личное приложение для скачивания своей коллекции с Яндекс Музыки в **FLAC**.

## Сценарий мечты (как хочет автор)

1. Один раз кладет OAuth-токен в `.env` файл. Больше ничего не вводит.
2. Вставляет ссылку на трек (позже — альбом/плейлист).
3. Нажимает «Скачать».
4. Файл падает в `downloads/` уже с тегами и обложкой.

Без: apt/brew/pip танцев, повторного ввода токена, выбора 10 опций.

## Почему FLAC — сложность

- Lossless отдает не обычный `download-info`, а отдельный эндпоинт `get-file-info?quality=lossless&codecs=flac,...&transports=raw|encraw`.
- Нужна подпись запроса: `HMAC-SHA256(ts+trackId+lossless+codecs+raw)` (Stmol) — ключи отличаются между проектами, надо сверить.
- Файл приходит зашифрованным `AES-CTR с нулевым IV`, ключ — hex из `downloadInfo.key`. Надо расшифровать.
- Контейнер может быть `flac` или `flac-mp4` (= `.m4a`). Расширение выбираем по факту, не по запросу.
- Если lossless нет (нет подписки / нет прав) — молча качаем лучший MP3 (320), помечаем в UI что это fallback.
- FLAC без тегов бесполезен для коллекции — теги обязательны.

## Проблемы текущего рабочего варианта (Stmol exe)

Со слов автора + подтверждено разбором кода:

1. Теги не пишутся / пишутся бедно: нет мультиартиста, нет `TRACKTOTAL/DISCNUM`, нет текстов, одна строка `A, B` вместо отдельных артистов.
2. UI неудобный: TUI на BubbleTea с табом, хоткеями `D/b/q/?`, формат один на всю очередь, `outputDir=./downloads` захардкожен, нет ретрая одного трека.
3. Плоские имена `Artist - Title.mp3` в одну папку — альбомы в кашу, нет `Album/01 - Title.flac`.
