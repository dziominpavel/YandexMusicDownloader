# Design

## Context

См. proposal.md. Нужно добавить лирику в теги, опциональные подпапки/.m3u, и всегда включённый UX без настроек.

## Goals / Non-Goals

**Goals:**
- Встраивать текст песни в теги по умолчанию (FLAC/MP3/M4A)
- Опционально сохранять `.lrc` при наличии синхронизированной лирики
- Опциональные подпапки по шаблону + экспорт `.m3u`
- UX: drag&drop, открыть папку, история, предпросмотр — всегда включены, без галочек в настройках

**Non-Goals:**
- Автоподстановка из буфера обмена
- Карточный UI полностью
- Поиск/плейлисты пользователя

## Decisions

### 1) Лирика
- **Получение**: добавить метод в downloader для получения лирики (по аналогии с API). Хранить в `Track` или отдельной структуре.
- **Встраивание**: расширить `tagger` для записи `LYRICS` (vorbis), `USLT` (ID3), `©lyr` (MP4). По умолчанию включено.
- **`.lrc` рядом**: сохранять только при `SAVE_LRC=true` и наличии таймингованной лирики, рядом с финальным файлом.

### 2) Подпапки
- **Путь**: вычислять финальный путь в UI/теггере перед публикацией, применяя шаблон с `%artist%/%album%/%year%` и санитизацией/правилом сортировки кириллицы из `docs/12-file-naming.md`.
- **По умолчанию**: `SUBDIRS=false`.

### 3) .m3u
- **Экспорт**: при скачивании альбома/плейлиста генерировать `.m3u` в директории треков, если `EXPORT_M3U=true`. Использовать относительные пути по возможности.

### 4) UX
- **Фронт**: drag&drop, кнопка открытия папки через `runtime.BrowserOpenURL`/`runtime.OpenDirectoryDialog` не нужно — просто открыть папку: в Wails можно использовать `runtime.ShellOpen` или `exec` на Windows. История в `localStorage`. Предпросмотр через отдельный вызов в Go (по ссылке получить превью-данные без полного скачивания).

## Risks / Trade-offs

- **[Риск]** Разные форматы лирики в API. → **Mitigation**: пробовать получить, при ошибке тихо пропускать.
- **[Риск]** Шаблон подпапок может дать пустые имена. → **Mitigation**: фолбэк на плоскую раскладку при невалидном шаблоне.
- **[Трейд-офф]** Предпроспросмотр делает доп. запросы. → **Mitigation**: кеш в памяти на время сессии, не блокирует Download.
