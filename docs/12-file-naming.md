# Правила именования файлов

Все скачанные файлы лежат **плоско** — прямо в папке загрузок (`OUTPUT_DIR`,
по умолчанию `downloads/`), без подпапок исполнителя/альбома.

Шаблон: `%artist% - %title%.%ext%`, где `%ext%` — реальный контейнер
(`flac`, `m4a`, `mp3`). Номер трека и альбом в имя не входят
(они есть в тегах). Запрещённые символы (`/ \ : * ? " < > |`)
заменяются на `_`, пробелы и точки по краям обрезаются.

## Кто считается русским

Код национальность не угадывает: правило простое — если **хотя бы один
кириллический символ** есть в имени исполнителя **или** в названии трека,
это свой, преобразование применяется. Если кириллицы нет ни там ни там —
это иностранец, имя остаётся нетронутой латиницей
(`Metallica — Enter Sandman` → `Metallica - Enter Sandman.mp3`,
никогда не `Мetallica`).

## Правило первого символа (сортировка)

Задача: русские исполнители сортируются отдельно от иностранных.
Преобразуется **только первый символ** имени исполнителя:

1. **Кириллица** — без изменений: `Амирчик - Не верю.flac`.
2. **Латиница с кириллическим двойником** — первый символ заменяется:
   `Mari Sa` → `Мari Sa`, `HEXXENMIND` → `НEXXENMIND`.
3. **Всё остальное** (латиница без двойника, цифры, символы) — впереди
   ставится префикс `ι ` (греческая йота, U+03B9, + пробел):
   `Noize MC` → `ι Noize MC`, `VAVAN` → `ι VAVAN`,
   `7Б` → `ι 7Б`.

Йота U+03B9 идёт по кодовой таблице между латиницей (до U+007A)
и кириллицей (с U+0400), поэтому такие имена при сортировке встают
после иностранных и перед русскими. Невидимый мягкий перенос U+00AD
пробовали — не годится: лингвистическая сортировка Windows его
игнорирует, и такие имена всплывают раньше всей латиницы.

## Таблица двойников (латиница → кириллица)

| Лат. | Кир. | Лат. | Кир. |
|------|------|------|------|
| A | А | a | а |
| B | В | — | — |
| C | С | c | с |
| E | Е | e | е |
| H | Н | h | н |
| K | К | k | к |
| M | М | m | м |
| O | О | o | о |
| P | Р | p | р |
| T | Т | t | т |
| X | Х | x | х |

Остальные первые символы (`G`, `J`, `N`, `V`, `W`, `Z`, цифры и т.д.)
двойников не имеют → невидимый префикс U+00AD.

## Примеры

| Исполнитель + трек | Файл |
|---|---|
| Амирчик — Не верю (FLAC) | `Амирчик - Не верю.flac` |
| Mari Sa — Моя Любовь (M4A) | `Мari Sa - Моя Любовь.m4a` |
| HEXXENMIND — Камин (FLAC) | `НEXXENMIND - Камин.flac` |
| Noize MC — Светлая полоса (FLAC) | `ι Noize MC - Светлая полоса.flac` |
| VAVAN — Велосипед (FLAC) | `ι VAVAN - Велосипед.flac` |
| 7Б — Знаю! Будет! (FLAC) | `ι 7Б - Знаю! Будет!.flac` |
| JANAGA — Солнце, море и смех (MP3 fallback) | `ι JANAGA - Солнце, море и смех.mp3` |

При нескольких исполнителях они склеиваются через `, `,
правило применяется к первому символу всей строки.
Если имя исполнителя пустое — файл называется только по треку;
если пусто и то и другое — по ID трека.
