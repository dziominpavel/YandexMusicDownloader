# Proposal

## Why

Проверка дублей сравнивает полные названия и пропускает радиоверсию: «Not Afraid» и «Not Afraid Radio Edit» дают низкую схожесть, поэтому вторая версия скачивается без предупреждения. Остальные пометки (remix, live, remastered, version, m4a/ФАКТ) пользователь считает разными записями; их трогать не нужно.

## What Changes

- Для проверки дублей добавляется сравнение базовых названий только по хвостовой пометке Radio Edit: без скобок, в скобках/квадратных скобках, в том числе с именем ремиксера перед ней.
- Если полные названия не совпали, базовые равны, а исполнитель совпадает или его схожесть не ниже обычного порога, файл показывается в существующем окне «Возможен дубль» с уверенностью 95%.
- Пометки Remix, Live, Remastered, Version, m4a, ФАКТ NNN, ИСКАЖЕН, feat., II, Part 2 и отдельный год не отбрасываются; 50%-подсказки для них не включаются, потому что пользователь признал такие пары ложными.
- Точное и нечёткое сравнение названий, `ScoreCandidate` (поиск лучшего качества), кэш и UI не меняются; файлы не удаляются автоматически.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `library-index`: добавляется требование учитывать только Radio Edit при поиске дублей.

## Impact

- Код: `src/internal/norm/norm.go` — функция снятия Radio Edit; `src/internal/library/match.go` — fallback в `FindMatches`; тесты `norm` и `library`.
- Схема кэша, UI, API, формат файлов и версия проекта не меняются.
- Поведение: предупреждение о радиоверсии того же исполнителя; остальные версии остаются разными записями.
