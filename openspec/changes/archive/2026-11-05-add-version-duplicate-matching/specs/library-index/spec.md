# Spec Delta

## ADDED Requirements

### Requirement: Учёт Radio Edit при поиске дублей

При проверке дублей приложение MUST сравнивать базовые названия, отбрасывая хвостовую пометку Radio Edit — в скобках, квадратных скобках и без них, в том числе с именем ремиксера перед ней. Совпадение базовых названий MUST показываться как возможный дубль с уверенностью около 95%, только если исполнитель совпадает или его схожесть не ниже обычного порога. Другие пометки версий и служебные пометки MUST NOT отбрасываться.

#### Scenario: Radio Edit без скобок

- **WHEN** в коллекции есть «Eminem — Not Afraid», а пользователь скачивает «Eminem — Not Afraid Radio Edit»
- **THEN** показывается окно «Возможен дубль» с уверенностью 95%, названием скачиваемого трека, именем и полным путём найденного файла; скачивание начинается только после «Скачать всё равно»

#### Scenario: Radio Edit в скобках

- **WHEN** в коллекции есть «Song», а скачивается «Song (Radio Edit)» или «Song [Radio Edit]»
- **THEN** файл считается возможным дублем

#### Scenario: Radio Edit с именем ремиксера

- **WHEN** в коллекции есть «Song», а скачивается «Song (2-4 Grooves Radio Edit)»
- **THEN** файл считается возможным дублем

#### Scenario: Другой исполнитель

- **WHEN** в коллекции есть «Artist A — Song», а скачивается «Artist B — Song (Radio Edit)»
- **THEN** предупреждение о дубле не показывается

#### Scenario: Радиоверсия, а не Radio Edit

- **WHEN** в коллекции есть «Song», а скачивается «Song (Radio Version)», «Song (Radio Mix)» или «Song (Radio Remix)»
- **THEN** предупреждение о дубле не показывается

#### Scenario: Другие версии не считаются

- **WHEN** в коллекции есть «Song», а скачивается «Song (Remix)», «Song (Live)», «Song (Remastered)» или «Song (Version)»
- **THEN** предупреждение о дубле не показывается

#### Scenario: Служебные пометки не отбрасываются

- **WHEN** в коллекции есть «Song (m4a) [ФАКТ 320]», а скачивается «Song»
- **THEN** предупреждение о дубле не показывается

#### Scenario: Название состоит только из Radio Edit

- **WHEN** название после снятия пометки становится пустым
- **THEN** такое название не даёт совпадений и не вызывает паники

#### Scenario: Поиск лучшего качества не меняется

- **WHEN** мониторинг качества сравнивает локальный «Song» с результатом поиска «Song (Live)»
- **THEN** live-версия не считается кандидатом на замену: правило Radio Edit действует только для проверки дублей
