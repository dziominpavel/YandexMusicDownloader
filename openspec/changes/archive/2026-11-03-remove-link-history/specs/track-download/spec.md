# Spec Delta

## MODIFIED Requirements

### Requirement: UX улучшения без настроек

Приложение MUST поддерживать drag & drop ссылок на окно, кнопку «Открыть папку загрузок» и предпросмотр ссылки (обложка, название, артист, кол-во треков для альбома/плейлиста). Предпросмотр MUST НЕ блокировать нажатие «Скачать»; при ошибке предпросмотра он MUST скрываться без ошибки. Все эти функции MUST быть включены всегда, без опций в окне настроек. Приложение MUST NOT хранить и показывать историю последних ссылок.

#### Scenario: Drag & drop

- **WHEN** пользователь перетаскивает ссылку Яндекс.Музыки на окно
- **THEN** ссылка подставляется в поле ввода и можно сразу скачать

#### Scenario: Открыть папку загрузок

- **WHEN** пользователь нажимает «Открыть папку загрузок»
- **THEN** системный проводник открывается на папке `OUTPUT_DIR`

#### Scenario: Предпросмотр ссылки

- **WHEN** в поле ввода вставлена валидная ссылка на трек/альбом/плейлист
- **THEN** показывается компактный предпросмотр (обложка, название, артист/кол-во треков). Нажатие «Скачать» работает независимо от предпросмотра; если превью не загрузилось — блок предпросмотра скрывается

#### Scenario: История ссылок

- **WHEN** пользователь вставил ссылку и запустил скачивание
- **THEN** выпадающий список истории не появляется, лог не перекрывается списком, а ссылка не сохраняется в localStorage
