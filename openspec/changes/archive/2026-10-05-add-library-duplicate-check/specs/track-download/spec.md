## ADDED Requirements

### Requirement: Проверка на возможный дубль перед скачиванием

Если включена индексация коллекции (`LIBRARY_DIR` задан, см. capability `library-index`), приложение MUST перед стартом скачивания каждого трека искать совпадения в индексе и при схожести выше порога показывать пользователю предупреждение о возможном дубле: с процентом совпадения, путём/именем найденного файла и упоминанием разного формата, если он отличается. Скачивание этого трека MUST начинаться только после подтверждения; после отказа трек MUST пропускаться с записью в лог. Если `LIBRARY_DIR` не задан, проверка MUST отсутствовать и скачивание MUST идти как раньше. Существующее поведение (`[skip] already exists` при точном совпадении имени файла, `[skip] duplicate` по повтору ID в плейлисте) сохраняется и дополняется этой проверкой, а не заменяется.

#### Scenario: Дубля нет

- **WHEN** в индексе нет файлов со схожестью выше порога
- **THEN** скачивание начинается без диалога, как обычно

#### Scenario: Найден похожий файл — подтверждение

- **WHEN** найден кандидат со схожестью выше порога (например 93%)
- **THEN** показывается предупреждение «возможен дубль» с процентом совпадения и именем файла из коллекции; по подтверждению трек скачивается, по отказу — не скачивается, а в логе появляется строка о пропуске

#### Scenario: Плейлист — подтверждение на каждый трек

- **WHEN** в плейлисте несколько треков совпали с файлами коллекции
- **THEN** по каждому такому треку запрашивается отдельное подтверждение; трек без совпадений качается без диалогов, а отказ по одному треку MUST NOT останавливать остальные

#### Scenario: Уже есть в другом формате

- **WHEN** в коллекции уже лежит такой же трек в MP3, а сейчас качается FLAC (или наоборот)
- **THEN** показывается предупреждение о возможном дубле с явным указанием, что найденный файл имеет другой формат

#### Scenario: Проверка выключена

- **WHEN** `LIBRARY_DIR` в `.env` не задан
- **THEN** диалогов о дублях нет, поведение полностью соответствует прежнему
