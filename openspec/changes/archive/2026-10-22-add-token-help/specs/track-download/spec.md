# Spec Delta

## MODIFIED Requirements

### Requirement: Токен из окружения

Приложение MUST читать OAuth-токен из переменной `YANDEX_TOKEN` (файл `.env`). Токен MUST также можно задать и проверить в окне настроек (см. capability `app-settings`), откуда он сохраняется в тот же `.env`; без токена приложение MUST предупреждать, что доступно только 30-секундное превью, и не падать. Предупреждение MUST подсказывать открыть настройки и встроенную справку «Как получить токен?».

#### Scenario: Токен задан

- **WHEN** в `.env` задан `YANDEX_TOKEN` и пользователь запускает приложение
- **THEN** приложение валидирует токен через `account/status` и готово к скачиванию

#### Scenario: Токена нет

- **WHEN** `YANDEX_TOKEN` пуст или отсутствует
- **THEN** приложение показывает предупреждение про 30-секундное превью и подсказку открыть «⚙ Настройки → Как получить токен?», продолжая работу

#### Scenario: Скачивание без токена

- **WHEN** пользователь нажимает «Скачать», а токен не задан
- **THEN** в логе появляется ошибка с подсказкой открыть настройки и справку «Как получить токен?»

#### Scenario: Токен задан в настройках

- **WHEN** пользователь ввёл токен в окне настроек, проверил его и сохранил
- **THEN** токен записан в `.env`, клиент пересоздан, скачивание работает с новым токеном без перезапуска
