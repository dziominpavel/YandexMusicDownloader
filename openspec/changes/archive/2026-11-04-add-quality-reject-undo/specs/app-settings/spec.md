# Spec Delta

## ADDED Requirements

### Requirement: Список отклонённых совпадений

Окно настроек MUST показывать в разделе мониторинга FLAC список отклонённых поисковых совпадений: локальный файл, найденный трек и дата отклонения. Для каждой записи MUST быть действие «Вернуть». Список MUST сохраняться между запусками и MUST обновляться после отклонения или возврата без перезапуска. При отсутствии записей MUST быть явное пустое состояние.

#### Scenario: Список после отклонения

- **WHEN** пользователь отклонил поисковое совпадение и открыл настройки
- **THEN** в разделе мониторинга FLAC видна запись с локальным файлом, найденным треком и датой отклонения

#### Scenario: Пустой список

- **WHEN** отклонённых совпадений нет
- **THEN** в разделе мониторинга FLAC показано явное пустое состояние, а не пустое место

#### Scenario: Возврат

- **WHEN** пользователь нажал «Вернуть» у записи в списке
- **THEN** запись исчезает, отклонение снимается, а скачивание не запускается

#### Scenario: Несколько записей

- **WHEN** для одного локального файла отклонены два кандидата
- **THEN** в списке видны обе записи, и возврат одной не удаляет вторую

#### Scenario: Перезапуск

- **WHEN** приложение перезапущено после отклонения
- **THEN** список отклонённых совпадений восстанавливается из журнала

#### Scenario: Список обновляется без перезапуска

- **WHEN** пользователь отклонил совпадение в окне найденного и затем открыл настройки
- **THEN** список уже содержит новую запись без перезапуска приложения
